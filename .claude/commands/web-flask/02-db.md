### Query functions (port from lib/fiveserver/data.py, drop all Twisted/deferred)

User queries:
- `find_user_by_id(conn, user_id: int) -> dict[str, Any] | None`
- `find_user_by_username(conn, username: str) -> dict[str, Any] | None`
- `find_user_by_hash(conn, hash_val: str) -> dict[str, Any] | None`
- `find_user_by_nonce(conn, nonce: str) -> dict[str, Any] | None`
- `browse_users(conn, offset: int, limit: int) -> list[dict[str, Any]]`
- `create_user(conn, username: str, serial: str, hash_val: str) -> int`  (returns new id)
- `update_user(conn, user_id: int, username: str, serial: str, hash_val: str) -> None`
- `lock_user(conn, user_id: int, nonce: str) -> None`  (set reset_nonce)
- `delete_user(conn, user_id: int) -> None`  (soft delete: deleted=1)

Profile queries:
- `get_profiles_for_user(conn, user_id: int) -> list[dict[str, Any]]`
- `get_profile_by_id(conn, profile_id: int) -> dict[str, Any] | None`
- `get_profile_by_name(conn, name: str) -> dict[str, Any] | None`
- `browse_profiles(conn, offset: int, limit: int) -> list[dict[str, Any]]`
- `get_profile_stats(conn, profile_id: int) -> dict[str, Any]`  (joins streaks, matches count)
- `create_profiles_for_user(conn, user_id: int) -> None`  (create 3 empty profiles, ordinal 0-2)

All queries use `DictCursor` so results are dicts, not tuples. All use parameterized SQL (no string formatting of user data).
